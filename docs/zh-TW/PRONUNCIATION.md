# AI 唸錯字怎麼辦：錯音表

語音克隆聲音好聽，但會唸錯字：多音字挑錯音、少見字亂猜、數字和符號唸成怪音。Dreamfab 的做法很簡單：**字幕寫原字，唸的時候換成同音的常用字**，用一張錯音表（`SAY`）記下來，以後每一集都自動套用。

中文 | [English](../en/PRONUNCIATION.md)

## 為什麼會唸錯
| 類型 | 例子 | 唸成 |
|---|---|---|
| 多音字挑錯音 | 供給（jǐ）、重啟（chóng）、亭長（zhǎng） | 供 gěi、zhòng 啟、亭 cháng |
| 少見字不會唸 | 宓妃、曹叡、磷化銦 | 亂猜一個音，或唸成形近字 |
| 專有名詞 | 光纖、叢集、女媧 | 纖唸成 qiān、叢唸錯 |
| 數字和符號 | 二〇二八、1,143、1.6T | 〇 唸成「圈」，逗號、小數點唸怪 |
| 英文縮寫和公司名 | ADR、Dow Jones | 有時拆字母，有時照中文猜 |

## 怎麼發現
1. **自動檢查**：
   - 旁白回來後先跑檢查：解說和廣告線用 `explain/narration.py <資料夾> check`，新聞線用 `news/make.py check DAY`。
   - 檢查會把旁白轉成逐字稿，再用拼音跟稿子比對，列出「聽起來不一樣」的地方和秒數。拼音一樣的同音字會直接放過，不會列出來。
2. **一定要聽**：語音辨識自己也會錯，尤其是英文名字和數字，常被寫成別的樣子。只看逐字稿就重唸，常常白花點數。
3. **以使用者的耳朵為準**：有些是習慣問題，不是對錯。例如有人把「瓶頸」唸成「瓶錦」，照他的習慣唸。

## 怎麼修：錯音表 `SAY`
```python
SAY = [("光纖", "光仙"), ("供給", "供擠"), ("叢集", "從集"), ("瓶頸", "瓶錦"), ("重啟", "崇啟"), ("銦", "因")]
```
- **成對寫**：（字幕寫的, 實際唸的）。
- **兩邊一樣長**：字幕和聲音的時間才能一個字對一個字。
- **選同音的常用字**：聲調也要一樣。字不用有意思，只要好唸、不會唸錯。
- **只換有問題的那幾個字**：例如「大叢集」只要換「叢集」。整個詞比單個字安全，因為單字換掉會連帶影響別的詞。
- **只改唸的**：字幕、搜尋用的字幕檔、封面都還是原字。

| 產線 | 錯音表放哪裡 | 什麼時候套用 |
|---|---|---|
| 說・解說、廣・廣告 | 每一集的 `project.py` 的 `SAY` | `narration.py jobs` 出旁白任務時、合成對時時 |
| 聞・新聞 | 節目的 `series.py` 的 `SAY`（單日 `day.py` 可以再加） | `news/make.py voice`、`redo`、對時時 |
| 戲・短劇、曲・MV | 不支援：台詞和歌聲跟影片一起生成 | 改寫台詞，或重拍那一顆鏡頭 |

**同一個節目共用一張表**：新聞放在 `series.py`，所有日子都會套用。解說和深度報導是一集一個 `project.py`，開新的一集時把上一集的表抄過去。

## 修好了要重唸哪些
- **只錯一兩句**：只重唸那幾句，再接回原本的旁白。新聞線用 `news/make.py redo DAY 4 9` → `submit DAY redo` → `splice DAY 4 9`。重唸的那一句要先套用錯音表，接點選在前後的停頓，停頓至少留 0.3 秒。
- **錯很多處**：整段重唸比較乾淨。旁白的時間會變，所以有主播露臉、對嘴的段落也要重做對嘴。圖和圖卡都可以沿用。
- **新的一段又唸錯別的字**：同一句可以混用新舊兩段錄音，各取唸對的部分，在停頓處接起來。
- **花費**：重唸一段旁白 50 點，重做一段對嘴 50 點；離峰（03:00–09:00）半價。

## 換之前先想想：不一定要用 `SAY`
- **數字寫國字**：「一千一百四十三」比「1,143」穩。新聞線的「唸的」那欄寫國字，字幕那欄寫阿拉伯數字。
- **英文照英文寫**：Dow Jones、Oracle、Apple 直接寫英文，主播就唸英文。字幕要中文名的話，新聞線可以把唸的和字幕分開寫。
- **改寫句子**：實在找不到同音字，就換個說法，例如「一路貶爵」改成「一路降爵」。
