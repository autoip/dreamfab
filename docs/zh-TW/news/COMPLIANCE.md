# 新聞線的法律紅線：出片前先過一遍

適用：每日快報（美股一分鐘）、深度報導，以及新聞頻道出的每一支片。
**每一集過兩次**：研究寫完、文案給使用者看之前一次；合成出片之前再一次。清單過不了就改稿，不出片。

中文 | [English](../../en/news/COMPLIANCE.md)

## 一、我們是什麼、不是什麼

- 我們做的是**新聞整理**：發生了什麼、數字多少、誰說了什麼。我們**不是投顧**。
- 台灣《證券投資信託及顧問法》第 4 條：對有價證券提供分析意見或推介建議、並直接或間接取得報酬，就是證券投資顧問。第 107 條：沒有主管機關許可就經營，處五年以下有期徒刑，併科新臺幣 100 萬到 5,000 萬元罰金。美股也在規範範圍內（財政部 76 年臺財證(二)字第 00900 號函）。
- 金管會證期局 112 年 6 月 13 日證期(投)字第 1120340840 號函（投信投顧公會〈認定經營證券投資顧問業務之問答集〉）：要**四個要件同時具備**才是經營投顧業務：
  1. 對有價證券提供分析意見或推介建議
  2. 直接或間接取得報酬
  3. 分析意見與報酬之間有對價關係
  4. 以經營投顧業務為目的，經常性、反覆為之
  是否構成，由司法機關依個案判斷。
- **一般性資訊不是投顧**（釋字第 634 號、問答集第六題）：市場基本統計、技術分析理論、金融商品的公開條款。問答集第四題列的典型紅線：對特定股票給**買賣時點、支撐壓力點、價位**。
- **我們的處境**：深度報導一集講一檔股票，形式上已經是「對特定有價證券的分析」（要件 1、4 都碰到）；靠的是沒有向觀眾收費、分析和收入沒有對價（要件 2、3）。所以**內容和收費兩邊都要守**。

## 二、四條紅線

| 紅線 | 可以 | 不可以 |
|---|---|---|
| 1. 個股投資建議（投信投顧法） | 客觀報導「分析師預估 EPS 多少」；轉述法說會、股東信、財報；多空論點並列、都標出處；列「接下來要看的訊號」 | 我們自己說買進、賣出、加碼、減碼、目標價、支撐壓力、進出時點、停損停利、「穩賺」、「看好／看壞」的結論。估值只能引述（「某機構說 32 倍算貴」），不自己下「貴、便宜」的判斷。AI 主播也不「推薦」 |
| 2. 不實資訊影響股價（證交法第 155、171 條） | 具名來源；SEC 文件、公開資訊觀測站、新聞稿；每個數字兩個來源對得上 | 沒有來源的傳聞；單一來源的「據傳」；自己推測的原因寫成事實。單一來源的寫進文案的「沒放進片中」清單 |
| 3. 未公開消息（內線交易） | 公司已經公告的訊息（SEC、公開資訊觀測站、新聞稿） | 來路不明的「內部消息」；製作團隊也不得利用稿子的內容在公開前買賣 |
| 4. 損害公司商譽（刑法第 310、313 條） | 根據公開資料寫「誰指控什麼、公司怎麼回應、現在結果」 | 把指控寫成事實、把放空報告當定論、還沒判的寫成有罪 |

## 三、收費與贊助

- **不向觀眾收費**：沒有會員、付費群組、課程、綁個股內容的打賞；不招收會員、不自稱老師。
- **贊助商不是券商、投顧、被報導的公司**；贊助買的是曝光，不是某一檔股票的分析。片中和說明欄都標明贊助。
- YouTube 廣告分潤算不算「間接報酬」沒有正式函釋（律師見解認為訂閱費、廣告費都可能算），所以內容那邊要守得更緊。

## 四、每一集必備

- 片尾和說明欄：「主播與聲音為 AI 生成｜本頻道非證券投資顧問事業，內容為新聞整理與公開資料，不構成投資建議」（問答集第六題第二項：非投顧事業宜揭露背景、附上非屬投顧事業的警語）。免責聲明不是護身符：內容越線，聲明無效。
- 資料來源卡列出來源。
- 爭議、訴訟、監管：寫「誰做了什麼、公司怎麼回應、現在結果」；沒判的寫還沒判。

## 五、出片前清單

研究寫完過一次，合成前再過一次：

- [ ] 沒有買賣、加碼減碼、目標價、支撐壓力、進出時點、停損停利
- [ ] 「看好／看壞」「貴／便宜」只出現在引述裡、有出處；結尾不下投資結論
- [ ] 每個數字兩個來源；單一來源的都在「沒放進片中」
- [ ] 傳聞不寫成事實；推測的原因寫「市場認為」並標出處
- [ ] 指控和判決分開；沒判的寫還沒判；公司的回應有寫
- [ ] 沒有未公開消息
- [ ] 片尾、說明欄有 AI 聲明＋非投顧警語＋資料來源
- [ ] 沒有收費、沒有招收會員；贊助商不是券商、投顧、被報導的公司

過不了的那一條：改稿再出片。拿不準的：留在文案的「沒放進片中」，並告訴使用者。
